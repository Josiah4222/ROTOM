# Quick Partner Reference Card

## 🤝 Manage Partners

### Access Admin
```
URL: /admin/rotom/partner/
```

### Add New Partner
1. Click "Add Partner"
2. Fill in:
   - Name: "Organization Name"
   - Logo: Upload image (PNG recommended)
   - Website: https://example.com (optional)
   - Order: 10, 20, 30... (lower = first)
   - Is Active: ✓ Check to display
3. Save

### Edit Partner
- Click partner name
- Change any field
- Save
- Refresh website

### Delete Partner
**Soft Delete** (Hide):
- Uncheck "Is Active"
- Save

**Permanent Delete**:
- Click partner name
- Click "Delete" button
- Confirm

### Reorder Partners
- Edit "Order" field
- Lower numbers appear first
- Use increments of 10

## 📏 Logo Guidelines

| Aspect | Recommendation |
|--------|----------------|
| Format | PNG (transparent) |
| Size | 200x200 to 400x400px |

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Not showing | Check "Is Active" is checked |
| Logo distorted | Use square/landscape format |
| Not clickable | Add website URL |
| Wrong order | Edit "Order" field |

## 💡 Pro Tips

- **Order numbers**: Use 10, 20, 30... for easy reordering
- **Logos**: Transparent PNG works best
- **File size**: Compress images before upload
- **Testing**: Hard refresh after changes (`Ctrl + Shift + F5`)
