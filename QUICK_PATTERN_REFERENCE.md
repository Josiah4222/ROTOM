# Quick Pattern Reference Card

## 🎨 Manage Navbar Patterns

### Access Admin
```
URL: /admin/rotom/navbarpattern/
```

### Add New Pattern
1. Click "Add Navbar Pattern"
2. Fill in:
   - Name: "My Pattern Name"
   - Image: Upload file
   - Height: 60 (pixels)
   - Opacity: 0.80 (0.00-1.00)
   - Is Active: ✓ Check to use
3. Save

### Switch Patterns
- Check "Is Active" for the pattern you want
- Uncheck others (or it happens automatically)
- Refresh website: `Ctrl + Shift + F5`

### Edit Pattern
- Click pattern name
- Change settings
- Save
- Refresh website

## 📏 Recommended Settings

| Setting | Subtle | Standard | Bold |
|---------|--------|----------|------|
| Height  | 40px   | 60px     | 80px |
| Opacity | 0.50   | 0.80     | 1.00 |

## 🖼️ Image Guidelines

- **Format**: PNG, JPG, or WEBP
- **Type**: Horizontal repeating pattern
- **Size**: Under 500KB
- **Seamless**: Left/right edges should match

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Pattern not showing | Hard refresh: `Ctrl + Shift + F5` |
| Pattern stretched | Adjust height to match image |
| Too visible/invisible | Adjust opacity (0.00-1.00) |
| Multiple patterns | Only check one as "Active" |
